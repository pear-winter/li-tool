# 🍐 梨梨工作台 3.6.1 · 无书摘版

基于梨梨上传的「梨梨工作台 v3.6.1 无书摘版」制作的 SillyTavern 原生 UI 扩展。保留原工作台页面、样式、预设与世界书编辑、聊天档案馆、分支、阅读器、翻译及工具管理。

## 安装

需要 SillyTavern 1.19+ 和已启用的酒馆助手 4.10+。工作台直接调用酒馆助手提供的世界书、预设及脚本接口，所以请保留酒馆助手扩展。

1. 在酒馆助手里关闭旧的「梨梨工作台」脚本，避免两个版本同时运行；不需要删除它或清理数据。
2. 打开酒馆「扩展 → 安装扩展」，粘贴：

   https://github.com/pear-winter/li-tool

3. 安装完成后刷新酒馆。
4. 点击原来的工作台顶部/悬浮入口，或扩展设置中的「🍐 打开梨梨工作台」。

本扩展无需把 JSON 再导入酒馆助手。以后通过酒馆扩展管理检查更新，完成后刷新。

## 数据与兼容

沿用原版 localStorage 键（包括 cyll-pear-hub-v1、sb-branches-v1 等），以及原版 IndexedDB 数据库名称。在同一浏览器、同一酒馆网址下可以继续读取已有设置、分支及档案数据。不同设备或不同网址不会自动同步。

安装过程不执行删除聊天、预设、世界书或清空配置操作。扩展关闭时移除入口、界面和监听；重新开启会重新初始化。酒馆助手未就绪时会等待，缺少接口则显示提醒。

## 改动范围

原脚本改为 ES 模块启动函数，直接使用当前酒馆页面。新增 manifest.json、加载时机处理、依赖检查、启停钩子和扩展设置入口；正文业务逻辑与 CSS 保留原版。

检查语法：`npm run check`。
测试使用模拟的酒馆/酒馆助手接口，不访问真实用户聊天，也不执行付费请求。真实酒馆的每一种编辑、导入导出和第三方主题组合仍需使用时验证。
