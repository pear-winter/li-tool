# 🍐 梨梨工作台 v3.9.4

这是公开版，已移除梨间雪桌宠、书摘的代码、入口和联动。保留预设、世界书、聊天档案馆、阅读器、回复分支、API、美化、工具、音乐与桌面歌词；歌词可以复制。

## 安装（二选一）

### 酒馆助手脚本

下载 `梨梨工作台_v3.9.4.json`，导入酒馆助手全局脚本库，替换旧的工作台脚本。

### 酒馆扩展

保持已有扩展安装方式，需要 SillyTavern 1.19+、已启用的酒馆助手 4.10+。

1. 在酒馆助手中关闭旧工作台脚本。
2. 打开「扩展 → 安装扩展」，填入 `https://github.com/pear-winter/li-tool`。
3. 安装后刷新，点击工作台入口或扩展设置中的「🍐 打开梨梨工作台」。已有安装可检查更新后刷新。

只启用脚本或扩展中的一个，无需删除或清空旧数据。扩展安装后不必再导入 JSON。

## 本版功能

- 正则与脚本独立分组，条目名称与分组选择分行显示；插件页签可自由排序。
- 当前歌单搜索默认收起，点击「我喜欢」旁的线条放大镜展开整行搜索框。
- 安装 [梨梨配音室](https://github.com/pear-winter/li-voice-studio) 后，可在工作台管理配音室，将聊天配音收藏到「我的语音」。未安装时会显示安装提示。
- 选取多个语音、调整顺序后合成为大配音，可添加 BGM；原条目会隐藏，拆分后恢复。
- 桌面歌词与阅读器继续保留，歌词可复制；阅读器可高亮、加粗及收藏。

## 网易云歌曲搜索

在音乐页的「网易云 · 登录 / 同步」中保存自己的 NeteaseCloudMusicApi Enhanced 服务地址，按需扫码登录。随后点击「搜索网易云歌曲」，输入歌名或歌手，选择目标歌单，即可翻页、加入歌单或播放。播放前也会加入所选歌单和「我的音乐」，重复加入不会产生重复条目。

请求使用 `/cloudsearch`，快速重新搜索或关窗会取消旧请求。播放和试听范围由网易云账号权限、地区和接口响应决定；不可播放的歌曲沿用自动跳过逻辑。登录凭证仅保存在当前标签页，歌单导出不包含它。

QQ 音乐和汽水音乐未接入账号；可导入普通音频文件和音频直链。加密缓存文件、歌曲分享页不等于可播放音频文件或直链。

## 数据与兼容

沿用旧公开版脚本 ID、localStorage 键（如 `cyll-pear-hub-v1`、`lili-music-cfg`）和 IndexedDB 数据库名称。同一浏览器、同一酒馆网址下沿用已有设置与数据；不同设备和网址不会自动同步。旧版桌宠、书摘页签配置会被过滤；已有书摘数据不会被主动删除。由私人完整版切换时，请先停用原脚本，再导入公开版。

## 维护与检查

`workbench.js` 为扩展入口函数形式，JSON 中的 `content` 为酒馆助手立即执行形式，业务内容一致。版本号为 3.9.4，名字不加功能后缀。

- `npm run check`：脚本语法检查。
- 安装开发依赖并运行 `npx playwright install chromium`，再运行 `npm test`。也可用 `CHROMIUM_PATH` 指定已有 Chromium 浏览器路径。
- 测试覆盖界面启动、11 个页签、桌宠和书摘入口移除、旧数据保留、世界书页、酒馆助手延迟加载，以及扩展启停。

测试使用模拟酒馆与网易云服务，不访问真实聊天和账号。真实网易云账号播放、所有酒馆版本及第三方主题组合仍需实际环境验证。
