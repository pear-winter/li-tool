# 🍐 梨梨工作台 v5.4.5

## 安装（二选一）

### 酒馆助手脚本

下载 `梨梨工作台_v5.4.5.json`，导入酒馆助手全局脚本库，替换旧的工作台脚本。

### 酒馆扩展

保持已有扩展安装方式，需要 SillyTavern 1.19+、已启用的酒馆助手 4.10+。

1. 在酒馆助手中关闭旧工作台脚本。
2. 打开「扩展 → 安装扩展」，填入 `https://github.com/pear-winter/li-tool`。
3. 安装后刷新，点击工作台入口或扩展设置中的「🍐 打开梨梨工作台」。已有安装可检查更新后刷新。

只启用脚本或扩展中的一个，无需删除或清空旧数据。扩展安装后不必再导入 JSON。

## 版本说明

本次同步用户提供的 v5.4.5 脚本。JSON 原样保留；扩展版仅将立即执行入口转换为异步导出函数，并适配扩展启动与停用流程。

🍐 梨梨工作台 公开版 v5.4.5
适配 SillyTavern 1.19 / 酒馆助手 4.x

【入口】
· 顶栏图标、悬浮图标、魔法棒、楼层底栏、书页侧栏都可以打开工作台，在「控制台」里选显示哪几个。
· 顶栏图标可选：默认梨梨 / 跟随当前美化的图标 / 自己上传；悬浮图标可换图、可存成方案。

【预设】
· 浏览、搜索、编辑聊天补全预设的条目，正文可全屏编辑，支持查找替换。
· 条目分组、拖动排序、范围归组，分组会同步显示在酒馆自带的预设面板里。
· 条目收藏库：把常用条目收藏起来，随时放进别的预设。
· 缝预设：从别的预设或世界书挑条目缝进当前预设，可以连续缝、一步步撤销。
· 导入导出、批量删除预设；导入同名预设时只替换不一样的条目，自己缝进来的条目会保留。
· 预设列表按最近使用排序；可以批量翻译条目。

【API】
· 存多套 API 配置（网址、密钥、模型），分组管理，一键连接到酒馆。
· 拉取模型、批量把模型存成配置，导入导出配置。

【酒馆美化】
· 浏览酒馆主题，网格或竖排两种视图，可收藏、自定义排序。
· 新建、改名、导入导出、批量删除主题；给每套主题上传预览图。
· 在工作台里直接编辑主题的颜色和自定义 CSS，可全屏编辑、上传背景。

【世界书】
· 浏览、搜索、编辑世界书和条目，正文全屏编辑，查找替换。
· 条目复制 / 转移到别的世界书，从别的世界书缝入条目，批量翻译。
· 导入导出、批量删除世界书。

【聊天档案馆】
· 角色图库：改名、换卡面、更新角色卡、链接世界书、导入导出、批量删除角色。
· 存档：浏览、改名、导入导出（JSONL / TXT）、批量删除，跨存档搜索并跳转。
· 沉浸阅读器：翻页或滚动阅读存档，加书签、划线标注。
· 楼层编辑：插入角色楼层或用户楼层、删除楼层、开启新档。

【回复分支】
· 查看当前聊天每一层的多个回复版本和分支，跳转到某一层。
· 从任意一层创建分支、整层克隆、插入楼层、写分支 IF，调整楼层顺序。

【书摘】
· 配合「书摘」脚本使用，在工作台里看划线笔记。

【工具】
· 正则：按全局 / 角色 / 预设分组管理，导入导出、打包 ZIP、查找替换。
· 酒馆助手脚本：分组、启用停用、导入导出。
· 插件：安装、检查更新、批量更新、删除。

【音乐】
· 网易云扫码登录、同步歌单、搜索歌曲；也可以导入本地音频、音频链接、歌单文件。
· 自建歌单、合成大配音、歌词存书摘。
· 悬浮唱片、悬浮播放器、桌面歌词，样式都能自己调；关掉工作台也能继续放。

【急诊室】
· 生成回复时自动备份，回复丢了、被覆盖了可以在这里找回。

【控制台】
· 当前聊天的 token 统计（预设、世界书分别占多少）。
· 字号、界面缩放、入口显示、标签页顺序和名称、翻译接口、后台功能开关。
· 楼层底栏的设置。

【书页侧栏】
· 从屏幕边缘拉出，把存档、角色、预设、世界书、脚本、正则、user、绑定存档、API、音乐、控制台和工作台各页收进一条侧栏。
· 开关点了马上生效；user 可以新建、删除；世界书可以直接挂全局。
· 阅读设置：字号、行距、正文颜色、背景，滚动或左右翻页阅读。
· 魔法棒：把魔法棒里常用的几项放进侧栏；酒馆原生页面也能从这里打开。

【楼层底栏】
· 常驻在输入框上面：顶楼、上一层、楼层进度条、下一层、最新一层、底楼、续写、编辑这一层、进入工作台。
· 最左边的小按钮可以把底栏收起，收起后发送键左边会出现同款小图标，点它再展开。
· 装饰可选默认进度条或樱花条，颜色可调，可以开毛玻璃，按钮可以开关和排序。
