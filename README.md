# 🍐 梨梨工作台 v3.8.7

本仓库不包含书摘和桌宠功能。保留预设、世界书、聊天档案馆、阅读器、回复分支、API、美化、工具、音乐与桌面歌词；歌词可以复制。

## 安装（二选一）

### 酒馆助手脚本

下载 `梨梨工作台_v3.8.7.json`，导入酒馆助手全局脚本库，替换旧的工作台脚本。

### 酒馆扩展

保持已有扩展安装方式，需要 SillyTavern 1.19+、已启用的酒馆助手 4.10+。

1. 在酒馆助手中关闭旧工作台脚本。
2. 打开「扩展 → 安装扩展」，填入 `https://github.com/pear-winter/li-tool`。
3. 安装后刷新，点击工作台入口或扩展设置中的「🍐 打开梨梨工作台」。已有安装可检查更新后刷新。

只启用脚本或扩展中的一个，无需删除或清空旧数据。扩展安装后不必再导入 JSON。

## 网易云歌曲搜索

在音乐页的「网易云 · 登录 / 同步」中保存自己的 NeteaseCloudMusicApi Enhanced 服务地址，按需扫码登录。随后点击「搜索网易云歌曲」，输入歌名或歌手，选择目标歌单，即可翻页、加入歌单或播放。播放前也会加入所选歌单和「我的音乐」，重复加入不会产生重复条目。

请求使用 `/cloudsearch`，快速重新搜索或关窗会取消旧请求。播放和试听范围由网易云账号权限、地区和接口响应决定；不可播放的歌曲沿用自动跳过逻辑。登录凭证仅保存在当前标签页，歌单导出不包含它。

QQ 音乐和汽水音乐未接入账号；可导入普通音频文件和音频直链。加密缓存文件、歌曲分享页不等于可播放音频文件或直链。

## 数据与兼容

沿用原脚本 ID、localStorage 键（如 `cyll-pear-hub-v1`、`lili-music-cfg`）和 IndexedDB 数据库名称。同一浏览器、同一酒馆网址下沿用已有设置与数据；不同设备和网址不会自动同步。旧版隐藏页签会被过滤；已有书摘数据不会被主动删除。

## 维护与检查

`workbench.js` 为扩展入口函数形式，JSON 中的 `content` 为酒馆助手立即执行形式，业务内容一致。版本号为 3.8.7，名字不加功能后缀。

- `npm run check`：脚本语法检查。
- 安装开发依赖并运行 `npx playwright install chromium`，再运行 `npm test`。也可用 `CHROME_PATH` 指定已有 Chromium 浏览器路径。
- 测试覆盖界面启动、原数据保留、世界书页、搜索分页/加入去重/播放调用、请求竞争/空结果/失败/关窗取消，以及扩展启停。

测试使用模拟酒馆与网易云服务，不访问真实聊天和账号。真实网易云账号播放、所有酒馆版本及第三方主题组合仍需实际环境验证。
